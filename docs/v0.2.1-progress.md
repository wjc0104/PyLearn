# 0.2.1 测试包记录

## 本轮范围

- 项目文件路径改用解析后的路径组件，修复 iOS 路径别名导致文件列出但无法打开的问题；修复重复打开时覆盖未保存内容的问题。
- 文件与整个文件夹分别选择。安全访问范围覆盖 NSFileCoordinator 协调读取、枚举及复制；保留子目录和二进制资源，失败显示结果并清理未完成的新副本。
- 子文件夹可浏览，新建文件后直接打开编辑器；独立脚本可复制到指定项目且不覆盖同名文件，原件保留。
- Git 凭据按服务地址保存在钥匙串，克隆、拉取和推送共用；提交重新检查已跟踪文件，覆盖同大小、时间戳未变化的编辑。
- 学习内容扩展为 25 章、100 道章节练习；原有练习 ID 保留。编辑器提供 30 个分类模板。
- 搜题页直接切换服务和模型；实际文字请求成功后才保存并切换，失败、取消不更换当前模型。出题等待时可取消请求并切换模型。
- 补全只保留最新待处理请求，错误高亮复用 ID，前缀与行列计算移到防抖之后。
- 用户已确认练习不输出是其代码未写对；未修改解释器或自动替用户调用函数，只补充 return / print 说明和运行测试入口。
