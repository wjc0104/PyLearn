# 0.2.3 输入性能与翻译修复记录

## 原因与修改

- 翻译结果只有正文，没有收起入口。增加顶部和底部收起按钮；展开保留同一次翻译内容，不额外请求 AI。
- 输入前校验原来每次拼接整份新文本再计算 UTF-8 长度；现在缓存已知文本及字节数，仅计算被替换片段的差值。实际文本变化后刷新快照，避免重复发布相同内容。
- SwiftUI 刷新时不再重复读取编辑器整份文本。仅外部文档内容变化时原样加载；外部重载会清除旧撤销历史，普通输入的撤销重做保留。
- 中文组词时普通界面刷新不改动输入法光标；外部重载结束组词并更新缓存。保留 Unicode 字节上限及非法范围检查。
- 关闭代码输入不需要的系统纠错、自动大写、拼写检查、智能引号和智能横线。主题仅在配置变化时应用，高亮范围不变时不重新设置。
- 补全位置准备移到后台，保留输入停顿后的分析和过期结果过滤；补全栏固定高度。空白完整语句不启动全局补全，显式候选选择与 Tab 缩进分开。
- 保留成员补全、关键字参数、多行调用及光标位于闭括号之前时的函数提示，字符串或注释里的括号不会误判为调用上下文。
