# PyLearn 0.2 设计
用户已在真机试用 0.1，要求在线题库、AI 出题、项目目录、复制错误、中文提示、控制台就近折叠、更多符号、智能补全、Git、字体主题和最新稳定 Python。2026-10-23 用户明确要求调用代码修改一起编译，授权直接实施。
沿用 SwiftUI、Runestone、CPython，最低 iOS 16.3，TrollStore 安装。

## 方案
- 控制台标题常驻，就近展开/收起、复制和清空，等待输入自动展开；错误卡片独立定位/复制，保留英文原文和中文说明。
- 保留已有脚本和学习记录，导入文件夹到本机副本，保留层级及 Python/JSON/CSV/TXT/资源；文件树、入口选择、文本编辑；运行工作目录与模块路径为项目根目录。路径不得逃逸根目录；拒绝符号链接，1000 文件/50 MiB 上限。
- 字号、等宽字体、导入字体、主题和自定义前景/背景；系统复制及明确复制代码/粘贴；更多符号、配对和模板；手机点选补全，外接键盘 Tab 接受。
- 升级 CPython 3.15.1（3.15-b2，已校验包哈希及 arm64 最低 iOS 13），同步桥接/标准库路径和新版语法验证。Jedi 静态补全同进程运行，不执行用户代码，不启子进程；解析能力不足时回退，不把补全失败当语法错误。
- 版本化在线题库，中文关键词/知识点/难度搜索，缓存离线练习，参考答案和真实函数测试。采用 MIT Exercism 内容，保留来源许可；当前上游 142 实践题+21概念题，先适配标准库可运行的实践题，逐步扩充。
- 用户允许自配 API Key 及费用，明确要求多服务商。预置 OpenAI、DeepSeek、通义、智谱、硅基流动、Moonshot、Gemini、Claude、Ollama、自定义；支持 OpenAI 兼容、Anthropic、Gemini 原生协议；可保存多配置。Keychain 保存密钥。默认 HTTPS，局域网 Ollama 允许 HTTP，界面明确提示。AI 仅显式点击出题才调用；只发关键词，不自动上传项目。生成内容需解析和运行参考答案测试；不能把 AI 文本当已经验证的题目。
- Git 采用纯 Python Dulwich（Apache-2.0 许可选项），初始化/HTTPS克隆、状态、差异、提交、历史、分支和快进拉取/推送；不自动覆盖分歧或本地修改；凭据不进入 URL、项目、日志。
- 原库成功读取后备份再迁移，元数据和文件原子写入；运行、分析和 Git 串行；下载和网络请求有界。
- Actions 供测试，Releases 独立发布。本轮构建 0.2.0 测试 IPA，不自动发布正式版。中文 README 保留 Codex 辅助标注。

## 验收
旧数据迁移、路径边界/目录层级、资源和跨文件 import、切换项目隔离、错误复制、输入展开、主题字体持久化、离线补全、题库参考答案测试、网络失败保留缓存、AI 无效响应/失败答案、Git 本地提交/分支/快进保护、3.15 标准库和新语法、IPA 架构/最低系统/签名/体积。
